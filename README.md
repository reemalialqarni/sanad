## Project Overview

Sanad is a conceptual digital service for managing lost and found items in airports. It helps travelers submit a lost-item report, track its status, respond to a potential match, and prove ownership without exposing sensitive item details or personal information.

This repository demonstrates how generative AI can support a UX/Product Design workflow: structuring prompts, drafting interface content, processing messy notes, planning the work, verifying outputs, and applying responsible-AI practices. AI supports organization and exploration; the designer remains accountable for every final decision.

## Design Challenge

> How might we create a unified and secure experience that enables a traveler to report a lost item, follow the search, and prove ownership after leaving the airport, without exposing personal data or sensitive item details?

## Selected Workplace Scenario

The portfolio follows one fictional scenario: a UX/Product Designer is developing the first version of Sanad for airport lost-and-found services. The primary user is **Noura Alotaibi**, a 32-year-old domestic traveler who realizes after boarding that she left a small black bag near airport security.

The designer must turn incomplete stakeholder notes into a clear product direction, create safe and understandable interface content, plan an MVP, evaluate AI-assisted recommendations, and document the human review behind the final work.

## Proposed MVP

- Submit a lost-item report.
- Capture approximate location and time.
- Add a description and optional image.
- Separate public descriptors from private ownership evidence.
- Track report status through a reference number.
- Notify the traveler of a potential match.
- Complete ownership-verification questions.
- Route the case to an airport employee for final review.
- Select airport pickup or a future shipping option.

The MVP does **not** allow AI to confirm ownership, release an item, expose finder details, or make an irreversible decision.

## Key Learnings

1. A fluent AI response is not automatically a reliable design recommendation.
2. Prompt structure improves relevance, but verification determines whether an output is safe to use.
3. Missing information must be marked as unknown rather than filled with assumptions.
4. Sensitive ownership evidence should be separated from general item descriptors.
5. AI may suggest a match, while identity verification and item release remain human decisions.

## Responsible Use Statement

This is a conceptual training project. It contains no real passenger, airport, medical, financial, or organizational data. Noura, all reports, interview-style notes, outputs, and evaluation examples are synthetic. They are learning artifacts and are **not presented as findings from real user research**.

All AI-assisted content was reviewed and edited by the trainee. Any production version would require real user research, accessibility testing, security review, legal review, and integration with authorized airport systems.
